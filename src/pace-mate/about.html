Running Tools

Pace, speed, and race targets without unit friction.

Pace Mate keeps metric and imperial running math in one place: finish times, pace, speed, common splits, race targets, and ultra distances.

Open web tool Download iOS version

What it does

Built for quick decisions before a workout or race.

The tool is designed around the values runners constantly convert: distance, finish time, pace, speed, and target splits.

Convert pace and speed

Move between min/km, min/mile, km/h, and mph without re-entering the same run.

Plan race targets

Save target finish times for common race distances and reuse them as defaults.

Check useful splits

See practical split times for track, road, marathon, and ultra distances.

How to use it

Start with whichever number you already know.

1 Choose a distance

Pick a race chip, select a longer distance, or enter a custom kilometer or mile value.

2 Edit pace, speed, or time

Change the input you know and the matching finish time, pace, and speed update together.

3 Save your targets

Use Settings for your common goals. The web version keeps them after refresh.

iPhone app

Use Pace Mate from your home screen.

The iOS version keeps the same runner-first calculations in a native app. Use the web tool when you are on desktop, and iOS when you are heading out the door.
